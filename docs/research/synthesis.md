## Where all five sources agree

- Achilles: progressive heavy tendon loading first-line (JOSPT CPG 2024);
  eccentric-only not special; load magnitude is the active ingredient.
  Habit-anchored dosing is legitimate **if counted and progressively loaded**
  ("3 counted dose days/week"); random sets are bonus volume. Pain rules:
  target 0–3/10, ceiling 5/10, settled by next morning, no weekly upward
  trend; morning first-step pain + stiffness are the monitoring dashboard.
- Return of spring is a staged continuum (slow capacity → fast non-flight →
  double-leg elastic → unilateral elastic → martial spring), criteria-gated,
  48–72 h between hard tendon days, springy work never first/cold. 3–6+
  months realistic.
- Flexibility: passive ROM is already sufficient; the kicking gap is ACTIVE
  ROM. Full-ROM strength work improves flexibility as much as stretching —
  suppleness and strength are largely the same exercises, plus relaxed
  long-hold stretching (~5–10 min per muscle per week plateaus the benefit).
- Knees/feet: deep knee ROM is trainable and safe (progressive, heel down);
  knees-over-toes principles supported, branding not; backward walking has
  modest real evidence; foot-intrinsic work is worthwhile; barefoot mat work
  is fine; protect first-MTP (sesamoid) from loaded hyperextension.
- Shoulder: keep everything currently comfortable (press, snatch, push-ups,
  handstands); drop behind-the-neck permanently (costs nothing); small cuff/
  scapular prophylaxis dose is cheap insurance; back-handsprings are a
  separate risk track and NOT a program goal (Feb 2026 flare = capacity
  answer). Stop signs: apprehension, instability sensation, persistent pain.
- Dose: 1–2 × 30–45 min/week + micro-dosing + kung fu is evidence-legitimate
  (weekend-warrior + VILPA + 30–60 min/wk strengthening literature); a second
  weekly session is the biggest available upgrade. Light DBs (4–7 kg) work
  only when sets approach RPE 8–9; honest ceiling exists for hinge/squat
  maximal strength.
- Lateral hip (undiagnosed): safe common-denominator loading (bridges,
  abduction, bird dog, hinges), avoid sustained compression (leg-crossing,
  long sitting) and aggressive stretching into pain; break up sitting.
  Refer out if red flags or no change in 6–8 weeks.

## Where sources differed → resolution

1. Micro-dosing sufficiency: agent said structured weighted sessions
   meaningfully better; oracle reconciled via "counted dose days" through
   habit anchors, clustering sets once loads get heavy. → Adopted oracle's
   framing (fits owner's habit-anchored constraint).
2. Return-to-sport gates: agent quoted ≥20–25 single-leg heel raises; oracle
   declined hard thresholds (expert-derived, not validated). → Use as
   informal self-checks, not exam gates.
3. Asymmetry: agent suggested 2:1 stiff-side dosing; oracle: default
   symmetric, re-test monthly, +1 set to a consistently restricted side for
   6–8 weeks. → Oracle's conservative version adopted; symmetry stays a
   positive goal, pursued by measurement not force.
4. Stretch dose: ≥5 min (agent, Thomas 2018) vs plateau ~10 min (oracle,
   Ingram 2025) per muscle per week. → Compatible: 5–10 min band.
5. Nordic hamstring lowerings: strong evidence (agent), absent from oracle's
   blocks. → Included as an option in knee/leg content (high kicks are
   hamstring territory).

## Session architecture (owner decision 2026-08-10)

Target lengths: **30 min** and **45 min** sessions, plus an **optional
~15-min post-workout stretch block**. Structure: 30 = warm-up(5) + main(~22)
+ close; 45 = warm-up(5) + main(~22) + secondary block(~15); +15 stretch
appendable to either. Schema composition handles this natively.

## Proposed systems (owner to choose)

### System 1 — "Clinic + Gym" (fully separate tracks)
Routines: Physio (30), Strength-DB (30/45), Strength-BW (30/45),
Active-Flexibility (30), Stretch (15, standalone or appended), Qigong
(30–45). MadFit stays.
- Pro: each session has one clear identity; simple choice; the physio session
  comprehensively covers every problem part.
- Con: rehab is a FREQUENCY game (Achilles ≥3×/wk loading; LEAP-style
  abductor work several ×/wk). With 1–2 sessions/week total, any week spent
  on strength starves the rehab unless habit-anchored work carries it.
  Achilles is covered by counted habit doses; hip/foot work is not.

### System 2 — "Everything integrated" (oracle's default)
Every session = warm-up + main + embedded rehab stations; no dedicated
physio routine.
- Pro: rehab frequency guaranteed regardless of which session is picked;
  most time-efficient.
- Con: no "get it all fixing" session; muddier identity; harder to notice
  rehab progress; conflicts with owner's stated preference.

### System 3 — "Clinic day + rehab riders" (RECOMMENDED hybrid)
- **Physio routine (30)** exists as the comprehensive fix-it session
  (~weekly): calf loading, tibialis, foot intrinsics, LEAP-style abductor
  set, bridges, bird dog, psoas raises + long-sitting lifts, cuff/scapular
  set, split-squat isometrics.
- Every other routine carries a **2-station "rehab rider"** (one calf
  station + one rotating hip/foot/cuff station), so problem parts get
  touched whichever session is picked.
- **Achilles counted dose stays habit-anchored** (out of app) as the
  frequency backbone; documented as a one-page reference card.
- Other routines: Strength-DB, Strength-BW, Active-Flexibility/kicking,
  Stretch (15), Qigong (30–45), MadFit.
- Rationale: rehab needs frequency, strength needs effort, flexibility needs
  weekly minutes — the hybrid gives each its schedule shape without making
  every session porridge, and honors the owner's clinic-day instinct.

## Qigong option

Classic long routine candidate: **Ba Duan Jin (Eight Pieces of Brocade)** —
~30 min at traditional pacing (8 movements × 6–8 slow repetitions).
Evidence: multiple systematic reviews/meta-analyses report improvements in
balance, flexibility, blood pressure, and wellbeing; trial quality is
generally low-to-moderate but consistently positive; excellent fit for
no-jump, joint-friendly, morning-cold constraints. Grade: moderate
(consistent but methodologically weak literature). Alternative: the owner's
own school's qigong set, encoded as data (ASK OWNER — likely more meaningful
to him). App format: long intervals (60–90 s/movement), text cards + voice;
WorkoutX GIFs will not exist for these — needs text-card support or another
visual source.
